# Ритм

Личный трекер привычек и целей. React + Vite во frontend/, Django REST API в backend/. Светлый интерфейс, локальный шрифт Golos Text, белый огонёк на синем фоне.

## Запуск

```sh
docker desktop start
docker compose up --build -d
```

Открыть http://localhost:3000. Создайте аккаунт. SQLite хранится в Docker volume tracker_data; обычная остановка контейнеров сохраняет данные.

```sh
docker compose logs -f
docker compose stop
```

Если Windows сообщает, что dockerDesktopLinuxEngine не найден, запустите Docker Desktop и дождитесь успешного `docker info`.

## Основные функции

- Все привычки: полный список независимо от дня недели, поиск, расписание, редактирование и удаление. После создания привычка открывается в этом списке даже в день отдыха.
- Сегодня: план по расписанию, выполнение и отмена отметки, фильтры.
- Календарь: по умолчанию компактная сетка полного месяца. Таблица месяца разбита на недельные блоки и адаптируется к телефону без горизонтальной прокрутки. Неделя/месяц, переключение периода, итоги дня.
- Привычки: создание, редактирование, удаление с подтверждением, категории и выбранные дни недели.
- Отметки: выполнено / не выполнено / без отметки; заметка до 500 символов. Будущие дни, дни до начала привычки и дни вне расписания закрыты для отметок.
- Цели: название, единица, целевой и текущий результат, необязательный срок, связь с привычками. Прогресс цели обновляется вручную; отметка привычки не изменяет его автоматически.
- Статистика: последние 14 дней, сравнение последних семи завершённых дней с предыдущими семью, текущая и лучшая серии.

Серия считается в запланированных выполнениях: дни отдыха её не прерывают. Незавершённый сегодняшний день сохраняет вчерашнюю серию до конца дня. Изменение расписания применяется ко всей истории расчётов, сами сохранённые отметки не удаляются. Календарный день определяется на сервере в Europe/Moscow.

## Авторизация и проверки

Имя: 3–30 символов, латиница, цифры, подчёркивание. Пароль: 8–128 символов, строчная и заглавная латинские буквы, цифра, без пробелов и кириллицы. Обязательно подтверждение; сервер проверяет распространённые пароли и сходство с именем. Старые аккаунты продолжают входить со своими паролями.

```sh
docker compose exec backend python manage.py test habits
docker compose exec backend python manage.py makemigrations --check --dry-run
```

Тесты используют отдельную временную БД. Миграции сохраняют старые привычки и историю; `--fake-initial` поддерживает переход с первой версии без миграций.

## Разработка

Backend: `pip install -r requirements.txt`, затем `python manage.py migrate --fake-initial` и `python manage.py runserver` из backend/.
Frontend: `npm install` и `npm run dev` из frontend/.

Перед публичным размещением задайте SECRET_KEY через окружение, настройте домен/HTTPS и ограничение попыток входа. Авторизация использует токен в localStorage. Шрифт распространяется под OFL, лицензия находится в frontend/public/fonts/.

## Проверка интерфейса

`npm --prefix frontend test` — клиентские регрессионные тесты расписаний, поиска, диапазонов дат и всех 60 месяцев 2024–2028. Серверные тесты включают сценарий «Спорт во все дни кроме четверга».

Результаты браузерной проверки сохранены в artifacts/calendar-layout-regression.json: создание спорта без четверга, сохранение после перезагрузки, изменение расписания, отметка через таблицу, отсутствие горизонтальной прокрутки сетки и таблицы на ширине 390, 872 и 1440 px. Проверка выполнялась в отдельном тестовом аккаунте; аккаунт после проверки удалён.

## Компактная таблица и цвета

На экранах от 1100 px таблица показывает весь месяц одним блоком: одна строка на привычку, все даты рядом, панель разделов сворачивается в иконки. На телефонах доступны сетка месяца и адаптивные недельные блоки. У каждой привычки сохраняется цвет; выберите готовый или свой цвет в форме редактирования. Старые привычки получают разные цвета миграцией.

## Профиль и общая серия

Профиль: редактирование отображаемого имени, логина и необязательной почты. Смена пароля требует текущего пароля и подтверждения нового. Токен текущего сеанса обновляется, старые токены перестают работать.

Главный огонёк показывает общую серию: день засчитан, когда выполнены все привычки по расписанию этого дня. Выходные без запланированных привычек нейтральны. Незавершённый сегодняшний день не обрывает вчерашнюю серию до конца дня. Есть текущая серия, рекорд и семь последних дней; после закрытия дня появляется короткая вспышка. При `prefers-reduced-motion` анимации отключены. Личные серии каждой привычки показываются отдельно.

Внутри диалогов используется отдельная область прокрутки с отступом от скруглённой рамки; кнопка закрытия закреплена. Стандартный аватар — локальный SVG.
